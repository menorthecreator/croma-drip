# Croma Drip

Estrutura preparada para a loja atual e para a futura evolução com
backend, painel administrativo, estoque, pedidos e área do cliente.

## Importante

A estrutura atual da loja foi preservada no nível raiz para não quebrar
caminhos como:

- assets/logo.png
- css/style.css
- js/products.js
- produto.html?id=...

As pastas `server/` e `admin/` ficam isoladas até a próxima fase.
