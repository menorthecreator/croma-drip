# Admin — fase futura

Esta pasta está reservada para o painel administrativo da Croma Drip.

Não coloque senhas, chaves privadas ou lógica de autenticação somente no navegador.

O painel deverá consumir a API do backend e trabalhar com autenticação real,
sessão segura e permissões de usuário.

Recursos previstos:
- login administrativo;
- produtos;
- estoque;
- pedidos;
- usuários;
- logs de alterações.
