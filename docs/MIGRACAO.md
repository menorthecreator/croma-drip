# Migração sem quebrar a loja

1. Copie os arquivos atuais para os mesmos caminhos desta estrutura.
2. Teste a loja exatamente como está hoje.
3. Não mova index.html, produto.html, css/, js/ ou assets/ nesta fase.
4. Desenvolva server/ e admin/ separadamente.
5. Só substitua products.js pela API quando o backend estiver pronto.
6. Faça a migração por etapas, mantendo uma versão estável da loja.
